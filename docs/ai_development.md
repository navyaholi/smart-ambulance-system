# AI-Assisted Development

## Overview

Artificial Intelligence tools were used during the development of the Smart Ambulance Route & Hospital Allocation System.

AI assistance was used to support:

- Code generation
- Code explanation
- Algorithm understanding
- Test case generation
- Error identification
- Documentation
- Code improvement

## Development Approach

The development process followed a specification-first approach.

The requirements of the project were identified first, and AI assistance was then used to help implement individual components.

The generated code was reviewed and tested before being accepted into the project.

## AI-Assisted Code Generation

AI assistance was used for developing and understanding components such as:

- Python data models
- Graph algorithms
- Dijkstra's algorithm
- Dynamic Programming
- Backtracking
- Branch and Bound
- Greedy ambulance allocation
- Functional programming
- Concurrent hospital availability checking
- Unit tests
